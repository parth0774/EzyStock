# EzyStock Inventory Management System

EzyStock is a web-based inventory management application built using **ASP.NET** and **C#** that enables users to efficiently track, update, and analyze product stock levels in real time. The system provides a streamlined interface for managing items, suppliers, and categories, ensuring smooth data operations and accurate inventory control.

The platform integrates **SQL Server** as the backend database to support CRUD operations and maintain data consistency across all transactions. Its intuitive frontend, developed with **HTML**, **CSS**, and **JavaScript**, allows users to visualize stock levels, receive low-stock alerts, and access detailed reports on product availability and movement.

EzyStock is designed to simplify warehouse and retail stock management through a responsive, reliable, and user-friendly interface.
